# Open Source

## Research Writing Skill

**Open-source AI-assisted writing toolkit**

Repository: [HairuFan/research-writing-rhetorical-skill](https://github.com/HairuFan/research-writing-rhetorical-skill)

### Overview

Research Writing Skill is an open-source toolkit for AI-assisted scientific writing with emphasis on:

- Meaning preservation
- Calibrated claims
- Rhetorical coherence
- Human-in-the-loop validation

### Contributions

- Developed an open-source toolkit for AI-assisted scientific writing with emphasis on meaning preservation, calibrated claims, and rhetorical coherence.
- Designed structured prompts and evaluation workflows to improve the consistency and quality of AI-assisted academic writing.

### Related skills

- LLM-assisted technical writing
- Prompt design
- Documentation
- Evaluation workflow design
- Human-in-the-loop validation
