Selected Data Science & Research Projects

BERT Classification & Fairness Analysis

Python · PyTorch · BERT · NLP · Integrated Gradients · Statistical Modeling

Investigated how transformer-based occupation classifiers generate predictions and how demographic disparities relate to textual features and attribution pathways.

  • Fine-tuned and evaluated a BERT classifier on 99,069 test biographies across 28 occupations, achieving 85.5% accuracy and 80.7% macro-F1.
  • Designed an Integrated Gradients pipeline quantifying contributions from gender markers, social-role proxies, and professional cues.
  • Evaluated pathway-level fairness using gender-specific true positive rate gaps, Spearman correlations, and robust regression; identified limits of token-level attribution for explaining group disparities.

Transformer Models · NLP Classification · Explainable AI · Fairness Metrics · Statistical Evaluation

Hybrid AI Decision Simulation

Python · DistilBERT · Predictive Modeling · Simulation · Sensitivity Analysis

Examined how algorithmic predictions interact with simulated decision priors and how weighting strategies affect accuracy and disparities.

  • Fine-tuned and evaluated DistilBERT across 28 occupations using 99,069 test biographies: 83.10% accuracy and 73.86% macro-F1.
  • Combined model predictions with gender-agnostic and gender-conditioned occupational priors.
  • Tested decision weights α = 0.10–0.90, observing configurations where accuracy declined and aggregate gender accuracy gaps increased from 0.64 to 3.96 percentage points.

Methodological note: Decision priors were simulated, not observed human-participant decisions.

Deep Learning · Simulation Design · Sensitivity Analysis · Responsible AI

Mutual Fund Event Study

R · Event Study · CAPM · Time-Series Analysis · Statistical Modeling

Investigated growth and value mutual fund performance surrounding Federal Reserve rate cuts.

  • Analyzed six U.S. equity mutual funds around three 2019 rate cuts, using ±30 trading days, six-month, and one-year windows.
